# History

Microsoft is a multinational company operating in the field of computer technology and software development. Its headquarters are located in Redmond, Washington, United States. It was founded by Bill Gates and Paul Allen in 1975.

![](/images/101_Bill_Gates_and_Paul_Allan.png)

_Fig. 1.1. Paul Allen (left) and Bill Gates (right) founding Microsoft in 1975_

The first version of the MS-DOS operating system was released in August 1981, and the graphical interface Windows 1.0 on November 20, 1985. The first version of the popular Microsoft Office productivity suite was released on November 19, 1990.

![](/images/102_Microsoft_Windows_1.0.png)

_Fig. 1.2. Microsoft Windows 1.0 released in 1983_

![](/images/103_Microsoft_Word_1.0.png)

_Fig. 1.3. Microsoft Word 1.0 released in 1989_

The Windows 8 and 8.1 operating systems were introduced on August 1, 2012 and August 27, 2013 respectively. Support for Windows 8 and 8.1 ended on January 12, 2016 and January 10, 2023 respectively. The latest major release of the widely used desktop operating system, Windows 10, was released on July 15, 2015.

![](/images/104_Microsoft_Windows_8.1.png)

_Fig. 1.4. Windows 8.1 released in 2013_

![](/images/105_Microsoft_Windows_10.png)

_Fig. 1.5. Windows 10 released in 2015_
