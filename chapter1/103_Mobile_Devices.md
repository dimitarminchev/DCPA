# Mobile Devices

Windows Phone is a mobile operating system (smartphones) developed by Microsoft, succeeding the Windows Mobile platform. Windows Phone offered a completely new vision and functionality, in step with modern lifestyles and constant Internet connectivity, combined with powerful hardware that provided an optimal multimedia experience.

![](/images/106_Windows_Phone_7.png)

_Fig. 1.6. Windows Phone 7 released in 2010_

The first Windows Phone 7 was announced on October 21, 2010, localized into 25 languages, available in 35 countries, and its apps were published in the Windows Phone Store. It was based on Windows Embedded Compact 7 (a version of Windows Embedded CE). Support ended on October 14, 2014.

![](/images/107_Windows_Phone_8.png)

_Fig. 1.7. Windows Phone 8 released in 2012_

The second generation, Windows Phone 8, was released on October 29, 2012, and Windows Phone 8.1 on April 2, 2014. Windows CE was replaced by the Windows NT kernel used in Windows 8. Apps for the platform were published in the Windows Phone Store. Support for Windows Phone 8 ended on January 12, 2016, and for Windows Phone 8.1 on July 11, 2017.

![](/images/108_Windows_Phone_10.png)

_Fig. 1.8. Windows 10 Mobile released in 2015_

On November 20, 2015, the Windows 10 Mobile operating system was introduced. It supported the Universal Windows Platform architecture. Apps were published and downloaded from the Windows Store. Support ended on June 11, 2019.
