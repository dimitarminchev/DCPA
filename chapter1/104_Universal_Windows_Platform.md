# Universal Platform

On September 13, 2011, during the Build conference, the Windows Store was introduced for distributing applications for PCs running Windows 8.

![](/images/109_Convergence_Journey.png)

_Fig. 1.9. History of Microsoft's application store evolution_

When the Windows Phone platform was introduced in 2012, the Windows Phone Marketplace was renamed to Windows Phone Store, which provided distribution for apps targeting Windows Phone mobile devices.

With the release of Windows 10, the Windows Phone Store and Windows Store were unified. The operating system moved to a single architecture called the Windows Universal Platform. Today the company's application store is called the Microsoft Store.

![](/images/110_Universal_Windows_Platform.png)

_Fig. 1.10. Architecture of the Universal Windows Platform for applications_

This tutorial introduces the reader to the exciting world of Microsoft technologies for developing universal applications for the Windows platform.
