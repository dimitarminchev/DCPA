# Включване на режима за разработчици

За да разработвате универсални приложения за платформа Windows е необходимо да включите операционната система в режим за разработчици, както е показано на _Фиг. 1.16 (a)_ и _Фиг. 1.16 (b)_.

![](/images/116a_Developer_Settings.png)

_Фиг. 1.16 (a). Включване на режима за разработчици_

![](/images/116b_Developer_Settings.png)

_Фиг. 1.16 (b) Включване на режима за разработчици_

{% hint style='danger' %}
#### Забележка
На фигурите е показано включване на режима за разработчици в операционната система Microsoft Windows 11.
{% endhint %}
