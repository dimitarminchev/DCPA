# Applications

This section presents a number of applications demonstrating development of **Universal Windows Platform** _(UWP)_ apps.

Development of each application in Microsoft Visual Studio starts by creating a project. A new project is created from the menu via: **File > New > Project**. You can also use the keyboard shortcut **Ctrl + Shift + N** to create a new project.
