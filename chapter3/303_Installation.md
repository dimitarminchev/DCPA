# Installation

You can download the free Community edition of the integrated development environment, **Microsoft Visual Studio Community Edition**, from the official website: [https://visualstudio.microsoft.com/](https://visualstudio.microsoft.com/).

![](/images/302_Visual_Studio_Website.png)

_Fig. 3.2. Microsoft Visual Studio 2026 Website_

For the development in this chapter we will use **Microsoft Visual Studio Community Edition 2026**; during installation be sure to select the **WinUI application development** workload/option.

![](/images/303_Installation_WinUI.png)

_Fig. 3.3. WinUI workload selection during installation_

Selecting additional developer tools increases the disk space required to install the IDE.

Proceed with the installation and wait for it to complete; the process may take a considerable amount of time.

![](/images/304_Visual_Studio_Installation.png)

_Fig. 3.4. Visual Studio Installation_
