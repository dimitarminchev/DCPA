# Applications

Creating any application in the integrated development environment **Microsoft Visual Studio 2026** starts by creating a new project (Fig. 3.5). 

![](/images/305_Visual_Studio_Start.png)

_Fig. 3.5. Creating a new project in Visual Studio_

On the next screen you choose the project type in **Microsoft Visual Studio 2026** (Fig. 3.6).

![](/images/306_Visual_Studio_Start.png)

_Fig. 3.6. Selecting the project type in Visual Studio_

On the final screen you choose the project name and the location where it will be stored in **Microsoft Visual Studio 2026** (Fig. 3.7).

![](/images/307_Visual_Studio_Start.png)

_Fig. 3.7. Choosing the project name and storage location in Visual Studio_
