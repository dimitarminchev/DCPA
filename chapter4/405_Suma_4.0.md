# Suma 4.0

Стартирайте интегрираната среда за разработка **Microsoft Visual Studio 2026**, създайте нов проект, като за име на проекта напишете: **Suma 4.0**.

## MainPage.xaml

Файлът съдържа изходния код от дизайна на потребителския интерфейс на разработваното приложениеL 

```xml
<!-- User Interface (UI): Suma 4.0 -->
<StackLayout Padding="20">

    <!-- Title -->
    <Label Text="Suma 4.0" FontSize="Large" />

    <!-- A -->
    <Label Text="A=" />
    <Entry x:Name="boxA" Keyboard="Numeric" />

    <!-- B -->
    <Label Text="B=" />
    <Entry x:Name="boxB" Keyboard="Numeric" />

    <!-- A+B -->
    <Label Text="A+B=" />
    <Entry x:Name="boxAB" Keyboard="Numeric" />

    <!-- Button -->
    <Button Text="Sum" Clicked="OnButtonClicked" />

</StackLayout>
```

## MainPage.xaml.cs

Файлът съдържа изходния код от бизнес логиката на разработваното приложение. 

```csharp
// Business Logic (BL): Suma 4.0
public partial class MainPage : ContentPage
{
    // Constructor
    public MainPage()
    {
        InitializeComponent();
    }

    // Button Click Event Handler
    void OnButtonClicked(object sender, EventArgs args)
    {
        var A = int.Parse(this.boxA.Text);
        var B = int.Parse(this.boxB.Text);
        var C = A + B;
        boxAB.Text = C.ToString();
    }
}
```
