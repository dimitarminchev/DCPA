## Applications

This section presents a number of applications demonstrating the development of universal applications for the Windows platform.

The development of each application in the integrated development environment Microsoft Visual Studio begins with creating a project. A new project is created from the menu by performing the sequence: **File &gt; New &gt; Project**. The shortcut key combination **Ctrl + Shift + N** can also be used to create a new project.
